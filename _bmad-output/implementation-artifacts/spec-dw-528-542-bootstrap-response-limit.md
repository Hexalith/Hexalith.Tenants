## Intent

**Problem:** DW-528 and duplicate DW-542 identify bootstrap authority token responses being fully buffered by `HttpClient.PostAsync` before the existing 64 KiB limit is applied. Oversized responses can consume unbounded response memory and bypass that later limit.

**Approach:** Retrieve response headers before buffering, then enforce the existing 65,536-byte limit while consuming the response. Preserve the delegated administrator subject check, secure authority validation, caller cancellation, whole-operation client timeout, and support-safe failure handling that prevents bootstrap command dispatch on acquisition failure. Prove streamed size boundaries, early rejection, bounded consumption, disposal, cancellation and normal bootstrap behavior; close only these two deferred records after verification.

</frozen-after-approval>
