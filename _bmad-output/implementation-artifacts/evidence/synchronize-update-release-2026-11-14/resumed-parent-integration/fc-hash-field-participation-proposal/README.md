# Private field-participation proposal

This is a new bounded quality-regression proposal, not an asserted general guarantee that unequal objects have unequal hashes. It exercises real public HashSet insertion and permits collisions. It rejects only complete pairwise-scan collapse for a finite family of equality-distinguishing constructor text/coordinate values. No numerical hash values, ordering, salt, hash algorithm or wall-clock budget are fixed.

The local repository already requires marker cache-key hashes to include every equality field (Story6.1 lines254–255), and several later model stories require field hash participation. Earlier source-formatting work explicitly removed general unequal-object/non-collision assertions; that limitation remains. Whether this bounded broader collection-quality criterion should be adopted for other DTOs remains a parent decision after real baseline/control proof. It is not a claim of observed generator slowdown: the retained actual Roslyn5.12 control called zero model hashes in its bounded path.

The proposal is private only; no owner source, existing gate, triage or package selection is changed. Constructor-created model values are public DTO samples, not an assertion that each combination is emitted by the parser. Literal controls and true outcomes will be retained before any owner adoption.
