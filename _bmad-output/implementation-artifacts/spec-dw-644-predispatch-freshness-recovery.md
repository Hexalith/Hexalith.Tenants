## Intent

**Problem:** DW-644 records that member removal refused before dispatch because freshness or preview evidence is unavailable enters UnableToVerify without command identifiers. Restoring current evidence leaves the operator stuck behind the tracking-loss guard.

**Approach:** Represent explicitly undispatched first refusals as resubmittable previews with the existing localized refusal explanation, no command identity and audit NotStarted. Once evidence recovers, require explicit submission and rerun all current authority, freshness, preview, confirmation and admission checks. Preserve fail-closed lost-tracking handling and exact same-ID recovery for potentially delivered commands. Close only DW-644 after regression verification and independent review.
