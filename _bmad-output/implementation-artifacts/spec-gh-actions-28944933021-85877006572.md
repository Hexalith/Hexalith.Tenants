## Intent

**Problem:** The `ci / aspire-tests` job `85877006572` in GitHub Actions run `28944933021` fails 21 `Hexalith.Tenants.IntegrationTests` cases after restore/build succeeds. The API structural test finds no generated `Hexalith.Tenants.Api.Generated.TenantsRestController`, all generated API route tests receive `404 NotFound`, and three hosted UI smoke tests miss their unauthorized route state because the API route surface is absent.

**Approach:** Align the `Hexalith.Tenants.Api` RestApi generator dependency so the default CI sequence, `dotnet restore` followed by `dotnet build --configuration Release --no-restore`, restores the same generator input that Release build consumes. Preserve explicit source-reference debugging, but make the published generator package the default dependency path.

## Boundaries & Constraints

**Always:** Keep `.slnx` restore/build usage, warnings-as-errors, centralized package versions, and the external API boundary where generated controllers delegate through `IEventStoreGatewayClient`. Preserve the root-declared submodule policy and do not modify submodule contents.

**Ask First:** Halt before changing the shared `Hexalith.Builds` workflow, editing `references/Hexalith.EventStore`, removing the external API generated controller surface, bypassing integration tests, or changing route/authorization semantics.

**Never:** Do not hand-write replacement Tenants API controllers, convert the API host back to domain/UI host references, weaken authorization expectations to accept 404s, add inline package versions, or use recursive submodule commands.
