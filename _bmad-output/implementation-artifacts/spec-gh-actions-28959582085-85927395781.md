## Intent

**Problem:** GitHub Actions run `28959582085`, job `85927395781` failed in `release / release` after `dotnet nuget push` had already published all five NuGet packages. The final failure was `[publish-containers] HEXALITH_ZOT_API_KEY is required to publish containers.`, so a missing container registry API key caused a partial release.

**Approach:** Add a Tenants-owned semantic-release preflight that verifies required publish secrets are populated before any irreversible package or container publishing command runs. Keep the existing shared Hexalith.Builds release workflow delegation and generated container publisher intact.

## Boundaries & Constraints

**Always:** Fail before `dotnet nuget push` when `NUGET_API_KEY` is empty or whitespace. When container publishing is requested by `HEXALITH_CONTAINER_PROJECTS` or the generated `.hexalith/release/publish-containers.sh` script exists, also fail before `dotnet nuget push` when `HEXALITH_ZOT_USERNAME` or `HEXALITH_ZOT_API_KEY` is empty or whitespace. Keep diagnostics support-safe: print secret names only, never secret values.

**Ask First:** Halt before changing the shared `Hexalith.Builds` reusable workflow, disabling container publishing, publishing packages outside semantic-release, weakening package validation, changing repository secrets, or reordering release so containers publish before packages.

**Never:** Do not hide the failure by ignoring missing registry credentials. Do not let NuGet packages publish when a required later container credential is already known to be missing. Do not recurse into nested submodules or modify submodule files.

## I/O & Edge-Case Matrix

| Scenario | Input / State | Expected Output / Behavior | Error Handling |
|----------|--------------|---------------------------|----------------|
| Complete release secrets | `NUGET_API_KEY`, `HEXALITH_ZOT_USERNAME`, `HEXALITH_ZOT_API_KEY`, and container mappings are populated | semantic-release continues to package validation, NuGet push, and container publishing | Any later publish error remains blocking |
| Missing NuGet API key | `NUGET_API_KEY` unset, empty, or whitespace | publish command fails before package validation and before `dotnet nuget push` | Error names `NUGET_API_KEY` without printing a value |
| Missing container registry API key | container publishing requested and `HEXALITH_ZOT_API_KEY` unset, empty, or whitespace | publish command fails before `dotnet nuget push`, preventing a partial NuGet-only release | Error names `HEXALITH_ZOT_API_KEY` without printing a value |
| Container publishing not requested | no container mappings and no generated publisher script | only the NuGet API key is required | Container registry secret checks are skipped |
