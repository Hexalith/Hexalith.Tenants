## Implemented policy and targeted evidence

Global grants use a complete bounded authenticated native prefix for the fixed `system/global-administrators/global-administrators` identity, followed by matching final incarnation/prefix proof. Unknown, malformed, changed, erased, gapped, legacy or over-bound evidence throws a fixed safe unavailable exception; verified nonmembership is false. Scoped successful reuse never becomes a cross-request authority cache. All six query gates independently establish their grants; stale projections and wire flags cannot restore them.

Tenant commands retain native verification. Global management commands use their existing locked/replayed membership gate and discard the unused wire hint, avoiding an actor self-call while `/process` holds that same actor. At the canonical server-matched `/query` POST/policy endpoint, only the unused SDK hint is stripped; independent owner detail/users permissions can then succeed while global evidence is unavailable. Spoofed paths/claims or missing/wrong endpoint metadata cannot select this shortcut. Real HTTP tests cover owner success, unavailable-source refusal at all six gates, current/removed/spoofed global management actors and zero source self-calls. The delegated native-read authority endpoint also checks `VerifiedQueryCaller.OriginalQuery.IsGlobalAdmin`, preserving its canonical wire-hint refusal after stripping. TenantOwnerAuthorityQueryHandler has no existing IsGlobalAdmin-based canonical rejection; its binding/native checks remain unchanged.

Fatal failures retain their original instances/wrappers across caller retirement, cancellation and deadline races. Cancelled async tasks carrying a fatal inner exception are inspected without waiting. Cleanup avoids redundant cancellation of completed/already-cancelled loads, so a provider's throwing callback cannot replace the original fatal. Red regressions are retained alongside green full suites. One configurable ten-second search budget covers windows, hydration and fallback, observes caller cancellation even for a noncooperating provider, cancels outstanding work and discards late/incomplete evidence. Debug timing contains only fixed stage names and elapsed milliseconds; disclosure assertions still inspect every captured message.
