# Architecture rubric review · 21 November 2026

**Decision needed on AD-12.** The spine covers the domain/UI boundaries, authoritative read and command paths, operations, and downstream enforcement. The operator's ability to release an unresolved lifecycle attempt needs an explicit contract.

| Severity | Finding and evidence | Disposition |
| --- | --- | --- |
| High | AD-12 holds the lease through an unverifiable outstanding attempt (`architecture.md:159`), and the PRD addendum requires terminal evidence (`addendum.md:28`). On a possibly delivered enable/disable command, **Stop tracking** forgets the attempt and releases the aggregate lease while the command outcome remains unknown. Another operation on the tenant can then acquire admission. The control works even when authority or connectivity prevents reopening the flow (`src/Hexalith.Tenants.UI/Components/Tenants/Lifecycle/TenantLifecycleActionAvailability.razor:445–468`). The ambiguous-dispatch regression explicitly clicks it and verifies that reconciliation ends (`tests/Hexalith.Tenants.UI.Tests/Components/TenantLifecycleActionAvailabilityTests.cs:2206–2241`). | Decide whether lifecycle commands may release admission on explicit abandonment without terminal evidence. Specify the next write's admission conditions and what the operator can still verify. Record local tracking release independently of the remote command outcome. |
| Medium | AD-12 permits unrelated aggregates to proceed, but the cross-component guidance still says the shared gate admits one operation per circuit (`architecture.md:159,543`). The PRD marks circuit-wide serialization as superseded (`prd.md:368`). The Tenants test acquires two aggregate keys concurrently and releases them independently (`tests/Hexalith.Tenants.UI.Tests/State/TenantAggregateCommandAdmissionGateTests.cs:90–105`). | Mark circuit-wide serialization as historical and scope sibling blocking to the same aggregate wherever command admission is described. |
| Medium | D6 describes the wire metadata as carrying only current, stale or unknown (`architecture.md:443–449,470–476`). Those are freshness classifications. The REST client also consumes the platform's projection lifecycle header (`src/Hexalith.Tenants.UI/Services/Gateways/TenantsRestQueryClient.cs:360–392,406–432`). The 304 regression supplies Rebuilding, Degraded, Unavailable and LocalOnly, expecting invalid metadata in each case (`tests/Hexalith.Tenants.UI.Tests/Services/Gateways/TenantsRestQueryClientTests.cs:1111–1137`). | Distinguish the projected freshness classification from the richer wire lifecycle. State that these four lifecycle values cannot validate cached data on a 304. |
| Low | AD-9 and the localization example correctly use indexed .NET placeholders (`architecture.md:138,585`). The PRD localization requirement still specifies named placeholders (`prd.md:354`). A translator following the PRD literally could replace an index with a name and break formatting. | Align the PRD wording with the adopted .NET format in a follow-up. Preserve semantic argument names in translator guidance and preserve indices in resource strings. |
