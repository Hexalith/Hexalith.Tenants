Direction Comparison

Direction Best fit Strength Tradeoff
1. Operations ShellGeneral admin consoleFamiliar, balanced, Fluent-nativeCommand lifecycle is secondary
2. Access Review SplitTenant access stewardshipStrong context preservationLess global overview
3. Command Lifecycle DeskFirst command-capable sliceBest truth model for pending changesHeavier for read-only browsing
4. Audit Evidence WorkspaceAuditor and support workflowsBest proof reconstructionNot ideal as first landing view
5. User Lookup FirstOffboarding and person-first incidentsFast cross-tenant user answerCan underplay tenant stewardship
6. Incident Containment BoardUrgent access-risk operationsStrong queue and recovery modelCould feel too incident-centric for routine work
